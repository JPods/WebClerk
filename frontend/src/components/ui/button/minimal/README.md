# Minimal Button Set

**Style:** Text + optional emoji — compact, keyboard-friendly, zero image weight
**Origin:** Built-in fallback — no external dependencies
**Format:** Inline text rendering — no files needed
**Size:** Adapts to font size

## Actions Available

| Label | Emoji | Action | Maps To |
|-------|-------|--------|---------|
| Add | + | Create new record | addRecord |
| Save | 💾 | Save / confirm | save |
| Discard | ↩ | Discard changes | discard |
| Delete | 🗑 | Delete one record | deleteRecord |
| Del Sel | 🗑 | Delete selected records | deleteSelection |
| Filter | 🔍 | Search / filter | filter |
| All | 📋 | Show all records | showAll |
| Subset | 📎 | Show selected subset | showSubset |
| Omit | 🚫 | Exclude selected | omit |
| Sort | ↕ | Sort records | sort |
| Print | 🖨 | Print / reports | print |

## Notes

Best for accessibility, screen readers, and low-bandwidth environments.
No images to load, no fonts to download. Works everywhere.
