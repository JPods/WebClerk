In WebClerk records have a .refs object to denormalize data queries and related documents

record.refs.tags is an array of user defined search words

record.refs stores denormalized values to simplify user searching. Each model has a setting record where model_name = the model name, purpose = "refs_setup". The data.object should contain the models and fields data should be denormalized from. 

Example, for model_name = "action" we will want to denormalize into keywords the name_first, name_last, phone number, email for all contact model records associated with the action and their company name.

By storing these instructions into a setting record for each model, users can adjust them to their specific needs.
