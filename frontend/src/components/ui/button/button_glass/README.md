# Glass Button Set

**Style:** WC2 glass chrome — warm highlights, metallic frames, 3D depth
**Origin:** WebClerk 2 era, designed for 4D desktop application
**Format:** PNG sprite sheets — 3 vertical frames (normal, hover, pressed)
**Size:** Original ~28px per frame, displayed at 56px

## Actions Available

| File | Action |
|------|--------|
| AddRecord.png | Create new record |
| OK.png | Save / confirm |
| Cancel.png | Discard changes |
| Delete Record.png | Delete one record |
| Delete Selection.png | Delete selected records |
| Query.png | Search / filter |
| ShowAll.png | Clear filters, show all |
| ShowSubset.png | Show selected subset |
| OmitSelection.png | Exclude selected from view |
| OrderBy.png | Sort records |
| Print.png | Print / reports |

## Notes

These buttons have personality and visual weight. Users from WC2 recognize them.
