# Training Videos

Short (1-4 minute) training video scripts for WebClerk 3 features.
Each script is designed to be recorded as a screen capture with voiceover.

## Scripts

| Script | Duration | Topic |
|--------|----------|-------|
| [button-style-selection.md](button-style-selection.md) | ~2 min | Choosing and using toolbar button styles |

## Recording Guidelines

- **Screen capture:** QuickTime Player (Mac) or OBS
- **Resolution:** 1920×1080 or Retina equivalent
- **Voice:** Clear, conversational, no jargon
- **Pace:** Show each click, pause 1 second after each action so viewer can follow
- **Length:** 1-4 minutes per video — if longer, split into parts
- **Format:** MP4, H.264
- **Storage:** Upload to `/Volumes/Allie/jpods/library/training/` and create Document record
