# Phosphor Duotone Button Set

**Style:** Modern duotone SVG — fill layer + stroke layer for visual depth
**Origin:** Phosphor Icons (MIT license, phosphoricons.com)
**Format:** React components rendered at runtime — no image files
**Size:** Scalable SVG, default 44px with hover lift + press scale

## Actions Available

| Component | Action | Maps To |
|-----------|--------|---------|
| FilePlus | Create new record | addRecord |
| FloppyDisk | Save / confirm | save |
| ArrowCounterClockwise | Discard changes | discard |
| Trash | Delete one record | deleteRecord |
| TrashSimple | Delete selected records | deleteSelection |
| Funnel | Search / filter | filter |
| ListBullets | Show all records | showAll |
| Funnel (active) | Show selected subset | showSubset |
| Prohibit | Exclude selected | omit |
| SortAscending | Sort records | sort |
| Printer | Print / reports | print |

## Notes

Duotone weight gives icons personality without chrome effects.
Hover lifts 8%, press scales down 8%, active gets colored border.
Danger actions (delete) render in red.
